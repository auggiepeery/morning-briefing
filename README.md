# Firstlight — Morning Briefing

Public sample UI for a personal morning briefing (America/Denver): greeting, Midway weather, sample school work, sample calendar, and sample stretch options.

## Stack

Next.js App Router + TypeScript. Weather comes from Open-Meteo (no API key). Other sections use in-app sample data only.

## Dev

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:5173](http://127.0.0.1:5173).
